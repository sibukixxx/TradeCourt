# TradeCourt

[English](README.md) | **日本語**

ローカルで動く **トレード判断の振り返りツール** です。行動する *前に* トレード仮説を書き出し、契約中の AI サービスに **賛成・反対の両面から反論** させ（コピー＆ペーストのみ、API キー不要）、**仮想取引（ペーパートレード）** の結果を記録して、計画と結果のズレから学びます。

> **売買シグナルのサービスではありません。** 売買の推奨・発注・ブローカー連携は行わず、リアルタイム価格があるかのような表示もしません。結果はすべてユーザーが入力する仮想取引です。投資助言ではありません。

画面は **英語と日本語** に対応しています（ブラウザの言語から自動判定、いつでも切り替え可能）。

## できること

| 画面 | 内容 |
| --- | --- |
| **01 Market Lens** | 手元の OHLC CSV（USD/JPY、`date,open,high,low,close`、最大5,000行・2MB）を取り込み、終値チャート・期間の高値/安値・騰落率を表示します。取り込み時に CSV のタイムゾーンを選びます。不正なファイルや大きすぎるファイルは取り込みません。リアルタイム配信はありません。 |
| **02 Scenario** | LONG/SHORT、1時間・4時間・日足、Entry・損切り・利確（リスクリワードをその場で表示）、根拠と無効化条件を登録します。保存後は変更できません。仮説を立てた時点の足（取り込んだ CSV）に紐付けることもできます。紐付けると、**方向だけ選べば** Entry・損切り（直近の高値/安値の外、または ATR×1.5）・利確（1.5/2/3R）を決まったルールで **自動下書き** します。推奨ではないことを明示しています。**R ボタン** で利確を損失幅の倍数から設定でき、Entry の初期値は最新の取込 CSV の終値です。 |
| **03 AI Court** | 選んでいる言語で BULL（賛成）/ BEAR（反対）のプロンプトを生成します。コピーして ChatGPT / Claude / Gemini / Grok の公式サイトで質問し、回答を貼り付けて保存します。AI 名・役割・日時を記録し、回答を並べて比較できます。貼り付けた文章は常にテキストとして表示します。 |
| **04 Journal** | 仮想取引の終了を1回だけ記録します。**ワンタップ**（利確 / 損切り / 建値、確認つき）でも、任意の価格の手入力でも記録できます。R 倍率を計算し、計画と実際の判断を比較します。**値動きとの照合** では、紐付けたシナリオについて、後から取り込んだ CSV で損切りと利確のどちらに先に届いたかを確認できます（先読みなし。1本の足で両方に触れた場合は「判定不能」）。**AI レビューの答え合わせ**（的中 / 外れ / 判定不能）もここで行います。 |
| **05 Insights** | 仮想取引の記録から判断のクセを集計します。平均R・勝率・ドローダウン、ルールを守った回と破った回の比較、CSV の値動きと比べた取り逃し / 軽減した R、AI 別の的中率を表示します。CSV / JSON でエクスポートできます。 |

スマホでも使えます（下部タブ、カード表示、押しやすいボタン）。

## はじめ方

必要なもの: Node.js 22 以上（corepack）、macOS または Linux（Windows は WSL）

```bash
make setup    # 依存関係のインストールとローカル DB（SQLite / D1）の作成
make seed     # 任意: 直近の USD/JPY 水準に合わせた合成デモデータを投入（アプリも起動）
make start    # API と画面をバックグラウンドで起動
make open     # http://127.0.0.1:5173 を開く
make stop     # 停止
```

- 画面: http://127.0.0.1:5173
- ローカル API: http://127.0.0.1:8787/api/health（このポートには画面はありません）
- `make` だけ実行するとコマンド一覧を表示します。

## 開発用のシードデータ

`make seed` は、**空の** ローカル DB に **合成（SYNTHETIC）** と明記したデモデータを入れます。毎回同じ内容になり、すべての画面にデータが表示されます。
- USD/JPY 日足 120 本。最終終値は直近の ECB 参照レート（159.7、2026-11-12）に合わせ、値動きの幅は直近の実際の範囲（153.27〜160.16）に収めています。
- シナリオ 8 件、AI 回答の例（「AI の回答ではない」と明記）、仮想結果 5 件、採点、ワンタップ記録を試すための未決済シナリオ 2 件を含みます。

オプション:
- `make seed ANCHOR=live`: 起動中のアプリ経由で、その時点の参照レートを基準にします。
- `make seed FORCE=1`: DB にデータがあっても追加します。
- `make reseed CONFIRM=yes`: バックアップを取ってから DB を初期化し、シードを入れ直します。**ローカルのデータが消える** ため、開発用の DB でのみ使ってください。

足のデータは乱数で作った合成データで、実際の価格ではありません。

## 言語

- 英語と日本語に対応しています。初回はブラウザの言語に合わせ、上部の **EN / 日本語** で切り替えると選択を記憶します。
- AI 向けプロンプトと自動下書きの文章も、選んだ言語で生成します。
- **言語を追加する手順:**
  1. `apps/web/src/i18n/<言語>.ts` を `ja.ts` と同じキーで作成します（足りないキーはコンパイルエラーになります）。
  2. `packages/core/src/lang.ts` の `Lang` に言語を追加します。
  3. `packages/core` にプロンプトと下書きのテンプレートを追加します（`buildReviewPrompt`、`draftLevels`）。

## 任意の参照レート（「現在値を取得」）

- ボタンを押したときだけ、ローカル API が api.frankfurter.dev から **欧州中央銀行（ECB）の USD/JPY 日次参照レート** を取得します。
  - キーやユーザーのデータは送りません。
  - リアルタイムの取引可能な価格ではないため、日付を併記します。
- 外部への通信を止めるには、`apps/api/.dev.vars`（Git 管理外）に `QUOTE_PROVIDER=off` と書いて `make restart` してください。

## 主な make コマンド

| 分類 | コマンド |
| --- | --- |
| 準備 | `setup`、`install`、`migrate`、`seed`、`reseed CONFIRM=yes` |
| 起動 | `dev`（前面）、`start` / `stop` / `restart` / `status` / `logs`（バックグラウンド）、`open` |
| 品質確認 | `test`、`typecheck`、`build`、`check`、`smoke`、`e2e`、`e2e-dev`、`verify` |
| ローカルデータ | `db-backup`、`db-restore FILE=…`、`db-reset CONFIRM=yes`（いずれも事前に自動バックアップ） |

`.run/`（起動状態）と `backups/`（バックアップ）は、個人の取引記録を含みうるため Git 管理外です。

## セキュリティ

**ローカル専用** で、**認証はありません**。
- API は `127.0.0.1` だけで待ち受け、localhost 以外からのアクセスや他サイトからの書き込みを拒否します。
- 認証などが整うまで公開環境にデプロイしないでください。
